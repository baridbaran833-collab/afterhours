# AFTERHOURS — The Rooftop

An immersive, single-location social-world prototype: a calm rooftop at night where you can wander, meet simulated visitors, listen to generative ambient audio, and leave a trace on the memory wall.

## Features

- Cinematic CSS-built rooftop, animated clouds, skyline, stars, and optional rain
- WASD / arrow-key exploration with a smooth player marker
- Interactive lounge, lantern, table, memory wall, and demo visitors
- Simulated social greetings and local-only chat
- A compact ambient audio player with generated browser audio, volume, and tracks
- Persistent memory wall with reactions via LocalStorage
- Evening/late-night mood controls and responsive mobile layout

## Tech

React, TypeScript, Vite, CSS, and Lucide icons. The environment is deliberately code-native and dependency-light for ordinary laptops.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Deploy to GitHub Pages

The included GitHub Actions workflow publishes the production `dist` folder whenever a commit reaches the `main` branch. During that build, Vite automatically uses the repository name as its base path, so JavaScript, CSS, and other bundled assets resolve correctly at `https://<owner>.github.io/<repository>/`. Local development continues to use `/`.

1. Create an empty GitHub repository for this project (do not add a README, `.gitignore`, or license through GitHub, since this project already contains them).
2. In the repository’s **Settings → Pages**, set **Source** to **GitHub Actions**.
3. Initialise Git locally, add the GitHub remote, commit the project, and push the `main` branch. The workflow at `.github/workflows/deploy-pages.yml` will then build and deploy automatically.
4. In **Actions**, open the “Deploy AFTERHOURS to GitHub Pages” run and wait for it to finish. GitHub will show the final Pages URL in the deploy job.

The prototype has no bundled image or audio files: environmental visuals are generated with React/CSS and the optional ambient sound is generated by the browser after a user interaction. No routing library is used, so there are no client-side route fallback requirements on Pages.

## Controls

- `WASD` or arrow keys: wander
- Click objects or visitors: interact
- Memory Wall: leave a short note (120 characters maximum)
- Bottom controls: ambient audio

## Current limitations

This is an offline visual prototype, not live multiplayer. Visitors, chat, and music are simulated/local. Generated audio requires a browser interaction to begin; memories are stored only in that browser’s LocalStorage.
